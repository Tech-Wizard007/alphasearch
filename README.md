## 📄 About alphasearch

alphasearch is a tool that helps you find information inside PDF documents. It works without complex setups like vectors, embeddings, or chopping files into pieces. Instead, it uses a logical search method inspired by AlphaGo’s decision-making.

You upload your PDFs, ask questions about their contents, and alphasearch finds answers with references to where they appear in the documents. It is designed for users who want quick and clear results without technical steps.

This tool supports files saved on your computer and answers about the information inside them. It works well with many topics you might find in documents like reports, articles, or manuals.

## 🔧 Using alphasearch

### How to Upload PDFs

1. Open alphasearch on your computer.  
2. Find the button or menu labeled “Upload” or “Add Documents.”  
3. Select one or more PDF files from your folders.  
4. Wait as the software processes these documents. This may take a few moments based on the file size.  

### How to Ask Questions

1. Type your question into the search box. For example, “What is the main conclusion of the report?”  
2. Press Enter or the search button next to the box.  
3. alphasearch will find the answer and show it with the page number or section from the PDF.  

### Tips for Better Results

- Use simple questions with clear words.  
- Upload documents that are not password-protected or corrupted.  
- Run one search at a time for best performance.
